# Copilotla Konuşan Komik Hesap Makinesi

## Bu Repo Nedir?

Bu, insanlığın en büyük buluşlarından biri: **GitHub Copilot ile abartılı şekilde konuşan, hiçbir işe yaramayan ama çok ciddi görünen bir hesap makinesi.**

Evet, duydunuz. 2+2'yi hesaplamak için Copilot'a danışır, sonsuz düşünür, sonra yine de doğru cevabı verir (bazen). Ciddi olarak komik. Komik olarak ciddi.

## Nasıl Çalışır?

```bash
python3 komik_hesap.py
```

Çalıştırın, gülün, sonra "neden böyle bir şey yaptım" diye düşünün.

## Özellikler

- Copilot ile gerçek (gibi) sohbet
- Abartılı sonuçlar
- Hiçbir işe yaramama garantisi
- Türkçe hata mesajları (yakında)
- Evrenin anlamını sorgulama

## Neden?

Çünkü neden olmasın? GitHub çok ciddi bir yer, biraz absürt olsun. Copilot da bunu onayladı (hayalimizde).

## Katkıda Bulunma

Lütfen daha komik hatalar ekleyin. PR'larınızı Copilot'a danışarak gönderin.
